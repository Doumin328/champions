      配信設定

      サービス

      YouTube でのストリームキー取得手順

      1. YouTube Studio を開く
      2. 左メニュー「ライブ配信」→「スケジュール設定なし」でライブ管理画面へ
      3. 「ストリームの設定」タブ → ストリームキー をコピーして上に貼り付ける

      RTMP サーバーは自動入力されます。ストリームキーのみ設定してください。

      Twitch でのストリームキー取得手順

      1. Twitch Creator Dashboard を開く
      2. 設定 → ストリーム → プライマリストリームキー をコピー
